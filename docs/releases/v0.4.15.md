# ARIL 0.4.15 — Brand wordmark and sidebar memory

Point release that uses the cyan **ARIL wordmark** across the app and site,
hides the duplicate system title when the sidebar is collapsed, and **remembers
sidebar open/collapsed state** across launches.

Builds are signed with Developer ID and **notarized by Apple** — no Gatekeeper
workaround needed.

## Install

1. Download **ARIL-0.4.15.dmg** from [aril.host](https://aril.host) or GitHub Releases
2. Open the disk image and drag **ARIL** into **Applications**
3. Launch ARIL (Solo mode starts the bundled gateway)
4. Open **Preferences → Subscription** to sign in with OpenRouter or paste an API key

If you already have ARIL 0.4.2+, you can also run **`/update`** in chat.

## What's new in 0.4.15

### Branding
- Empty hero, title-bar About control, and About panel use the same cyan/white
  wordmark image as aril.host (replacing plain “ARIL” text).
- Site header and hero screenshot updated to match.

### Sidebar
- Collapsing the session sidebar no longer exposes a second “ARIL” system title
  next to the wordmark.
- Sidebar open/collapsed state is saved and restored on the next launch.

## Requirements

- **Apple Silicon Mac** (M-series) with **macOS 14** (Sonoma) or newer
- An [OpenRouter](https://openrouter.ai/keys) API key with a small credit balance

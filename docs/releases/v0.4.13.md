# ARIL 0.4.13 — Incognito, slow-response fallback, and HTML previews

Point release with **Incognito** sessions, configurable **slow-response
fallback**, sandboxed **HTML/JS previews**, and clearer chat scroll controls.

Builds are signed with Developer ID and **notarized by Apple** — no Gatekeeper
workaround needed.

## Install

1. Download **ARIL-0.4.13.dmg** from [aril.host](https://aril.host) or GitHub Releases
2. Open the disk image and drag **ARIL** into **Applications**
3. Launch ARIL (Solo mode starts the bundled gateway)
4. Open **Preferences → Subscription** to sign in with OpenRouter or paste an API key

If you already have ARIL 0.4.2+, you can also run **`/update`** in chat.

## What's new in 0.4.13

### Incognito
- Ghost checkbox beside Auto / Manual / Judge — session context stays for the turn,
  but prompts are not stored in history, Learning, or logs.
- Transcript is wiped when the session ends or ARIL quits; monthly/weekly spend totals remain.
- Control stays available after restart (Incognito itself never survives quit).

### Slow-response fallback
- Preferences → General → **Slow-response fallback** — first-token timeout
  (default **30s**, or Off / 15–300s).
- In **Auto**, a silent hang cancels and retries once on a faster peer.
- Optional **Also use in Manual mode** (off by default).
- Skips Judge, reasoning-ish models, and turns already using MCP tools.

### Sandboxed HTML / JS previews
- Fenced ` ```html ` (or ` ```html-preview `) runs in an offline WebKit sandbox.
- Runnable JS uses ` ```js-preview ` / ` ```javascript-preview `; plain
  ` ```javascript ` stays as code only.
- No network, forms, or frames — Run / Reload / Stop in the preview chrome.

### Chat chrome
- **↑ / ↓** scroll to the start or latest message in the session.
- **Send** uses a paper-plane icon and highlight color so it is distinct from scroll.

## Requirements

- **Apple Silicon Mac** (M-series) with **macOS 14** (Sonoma) or newer
- An [OpenRouter](https://openrouter.ai/keys) API key with a small credit balance

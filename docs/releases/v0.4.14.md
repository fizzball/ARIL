# ARIL 0.4.14 — Project files and image-gen fixes

Point release with **Project files** (local RAG-lite context for sidebar
Projects), clearer project UI, and fixes for **generated images** that were
collapsing into omitted placeholders.

Builds are signed with Developer ID and **notarized by Apple** — no Gatekeeper
workaround needed.

## Install

1. Download **ARIL-0.4.14.dmg** from [aril.host](https://aril.host) or GitHub Releases
2. Open the disk image and drag **ARIL** into **Applications**
3. Launch ARIL (Solo mode starts the bundled gateway)
4. Open **Preferences → Subscription** to sign in with OpenRouter or paste an API key

If you already have ARIL 0.4.2+, you can also run **`/update`** in chat.

## What's new in 0.4.14

### Project files
- Right-click a Project → **Files…** to attach Word (`.docx`), Excel (`.xlsx`),
  PDF, RTF, CSV/TSV, or Markdown/text.
- Text is extracted locally under Application Support; sessions in that project
  get a file inventory plus keyword-matched excerpts in the system prompt.
- **Show in Finder** opens the project’s stored files folder; per-file reveal
  is available from the list.
- **Search…** for sessions inside a project is on the project context menu
  (search field is hidden until you open it).

### Project UX
- Selected sessions inside a Project use a distinct sidebar highlight from
  ungrouped sessions.
- Asking to “list project files” answers from Project knowledge and no longer
  runs OS Access `ls` on your Mac home (use `@OS` when you want the shell).

### Generated images
- Image-generation turns skip the slow-response fallback that could cancel long
  first-token waits.
- Inline bitmaps are persisted as `file://` links instead of vanishing into
  `omitted-from-context` placeholders after storage sanitization.

## Requirements

- **Apple Silicon Mac** (M-series) with **macOS 14** (Sonoma) or newer
- An [OpenRouter](https://openrouter.ai/keys) API key with a small credit balance

# ARIL 0.4.16 — OS Access approval and model bypass

Point release that requires **inline approval** before OS Access runs a shell
command, can **bypass models** that stall on the first token, and avoids empty
assistant bubbles after a timeout fallback.

Builds are signed with Developer ID and **notarized by Apple** — no Gatekeeper
workaround needed.

## Install

1. Download **ARIL-0.4.16.dmg** from [aril.host](https://aril.host) or GitHub Releases
2. Open the disk image and drag **ARIL** into **Applications**
3. Launch ARIL (Solo mode starts the bundled gateway)
4. Open **Preferences → Subscription** to sign in with OpenRouter or paste an API key

If you already have ARIL 0.4.2+, you can also run **`/update`** in chat.

## What's new in 0.4.16

### OS Access
- Proposed shell commands show **Run** / **Cancel** in the chat bubble before
  anything executes on your Mac.

### Non-responsive model bypass
- Preferences → General — after a first-token timeout, skip that model for Auto,
  Judge, and fallback retries for a configurable period (default 15 minutes),
  or permanently until you clear it.
- Active bypasses are listed in Preferences; clear one or all anytime.
- Manual mode still honors your locked model.

### Reliability
- Timeout / fallback paths no longer leave a blank assistant reply when the
  retry produces no content.

## Requirements

- **Apple Silicon Mac** (M-series) with **macOS 14** (Sonoma) or newer
- An [OpenRouter](https://openrouter.ai/keys) API key with a small credit balance

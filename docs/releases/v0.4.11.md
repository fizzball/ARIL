# ARIL 0.4.11 — Skills, Web Search prefs, and safer resets

Point release that adds local **Skills** (OS Access and Document Export), moves
**Web Search** into Preferences (on by default), keeps projects across `/reset`,
and ships the adaptive mesh identity.

Builds are signed with Developer ID and **notarized by Apple** — no Gatekeeper
workaround needed.

## Install

1. Download **ARIL-0.4.11.dmg** from [aril.host](https://aril.host) or GitHub Releases
2. Open the disk image and drag **ARIL** into **Applications**
3. Launch ARIL (Solo mode starts the bundled gateway)
4. Open **Preferences → Subscription** to sign in with OpenRouter or paste an API key

If you already have ARIL 0.4.2+, you can also run **`/update`** in chat.

## What's new in 0.4.11

### Skills
- Preferences → **Skills** — master switch plus per-skill toggles (MCP-style).
- Type **`@`** in the prompt to pick a skill.
- **OS Access** — run local shell commands (e.g. `dig`, `ls`); use `@OS` or natural language when the skill is on. Results show under **OS Access · …**.
- **Document Export** — save a reply (or the whole session) as PDF or Word with `@Document` or **`/save pdf|docx`** (add `session` for the full chat). Default Save names use `ARIL-yyyy-MM-dd-HHmmss`.
- **`/skills`** — list or enable/disable skills (`list` / `enable` / `disable` [id]).
- Skills respect the master switch — `@OS` does not run when Skills are off.

### Web Search
- **Web Search** moved to Preferences → **General** (enabled by default; persisted).
- Removed from the prompt toolbar; **`/web`** still toggles on/off/status.
- **`/status`** Connectivity section shows Web Search on/off.

### Projects & reset
- **`/reset`** clears ungrouped sessions and Learning data, but **keeps projects and sessions inside them**.
- Delete a project from the sidebar **right-click** menu.
- Preferences → **Delete all past sessions** still wipes everything (including projects) and now warns accordingly — use `/reset` for everyday cleanup.

### Branding
- Adaptive mesh app icon and in-chat marks; avatars tint by selected model.
- Menu bar icon uses a high-contrast template mesh and pulses while busy.

### Also in 0.4.11
- Help guide at [aril.host/help](https://aril.host/help/), linked from the macOS **Help** menu.
- Preferences → Appearance: choose app text size and typeface.

## Requirements

- **Apple Silicon Mac** (M-series) with **macOS 14** (Sonoma) or newer
- An [OpenRouter](https://openrouter.ai/keys) API key with a small credit balance

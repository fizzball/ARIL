# ARIL 0.4.12 — Build-aware update checks

Hotfix so `/status` and `/update` notice newer builds of the same marketing
version (for example 0.4.11 build 78 → build 79).

Builds are signed with Developer ID and **notarized by Apple** — no Gatekeeper
workaround needed.

## Install

1. Download **ARIL-0.4.12.dmg** from [aril.host](https://aril.host) or GitHub Releases
2. Open the disk image and drag **ARIL** into **Applications**
3. Launch ARIL (Solo mode starts the bundled gateway)
4. Open **Preferences → Subscription** to sign in with OpenRouter or paste an API key

If you already have ARIL 0.4.2+, you can also run **`/update`** in chat (marketing
version bumps are still detected on older builds).

## What's new in 0.4.12

### Update checker
- Compares **build numbers** when the marketing version matches (via `aril.host/downloads/latest.json`).
- `/status` Version line shows installed and latest as `0.4.x (build N)`.
- Sidebar **Update** appears for same-version build bumps after this release.

## Requirements

- **Apple Silicon Mac** (M-series) with **macOS 14** (Sonoma) or newer
- An [OpenRouter](https://openrouter.ai/keys) API key with a small credit balance

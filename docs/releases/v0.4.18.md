# ARIL 0.4.18 — Image reply cost tags

Point release that restores the **model / tokens / cost** tag line under
generated-image replies.

Builds are signed with Developer ID and **notarized by Apple** — no Gatekeeper
workaround needed.

## Install

1. Download **ARIL-0.4.18.dmg** from [aril.host](https://aril.host) or GitHub Releases
2. Open the disk image and drag **ARIL** into **Applications**
3. Launch ARIL (Solo mode starts the bundled gateway)
4. Open **Preferences → Subscription** to sign in with OpenRouter or paste an API key

If you already have ARIL 0.4.2+, you can also run **`/update`** in chat.

## What's new in 0.4.18

### Image generation
- Assistant replies that include a generated image again show the usual
  `[ model · tokens used … : cost = $… ]` tag under Copy image / Save…
- Cause: rewriting inline `data:image` payloads to on-disk `file://` links was
  regenerating message UUIDs, so the cost footer could not be attached.

## Requirements

- **Apple Silicon Mac** (M-series) with **macOS 14** (Sonoma) or newer
- An [OpenRouter](https://openrouter.ai/keys) API key with a small credit balance

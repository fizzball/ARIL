# ARIL 0.4.17 — SSLyze scanner and timeout retry prompt

Point release that adds a managed **SSLyze** TLS/certificate MCP scanner, keeps
**model/cost tags** across app restarts without duplicating turns, and prompts
you to pick a **retry model and timeout** after a first-token stall.

Builds are signed with Developer ID and **notarized by Apple** — no Gatekeeper
workaround needed.

## Install

1. Download **ARIL-0.4.17.dmg** from [aril.host](https://aril.host) or GitHub Releases
2. Open the disk image and drag **ARIL** into **Applications**
3. Launch ARIL (Solo mode starts the bundled gateway)
4. Open **Preferences → Subscription** to sign in with OpenRouter or paste an API key

If you already have ARIL 0.4.2+, you can also run **`/update`** in chat.

## What's new in 0.4.17

### SSLyze TLS / certificate scanner
- Enable **SSLyze Scanner (local)** in Preferences → MCP (same pattern as Nmap
  and Semgrep).
- Tools: certificate info, Mozilla intermediate scan, protocol support, classic
  TLS vuln checks, and custom flags.
- Install the CLI with `brew install pipx && pipx install sslyze`.
- Only scan hosts you own or are authorized to test.

### Session history
- Model/cost footers survive quit and relaunch.
- Duplicate user→assistant turns from stream/upsert races are collapsed on load.

### Slow-response fallback
- After a first-token timeout, ARIL asks which model to retry with and which
  timeout to use (defaults to Preferences → General).
- The chosen timeout is applied to the retry — no more silent fallback with the
  watchdog disabled.

## Requirements

- **Apple Silicon Mac** (M-series) with **macOS 14** (Sonoma) or newer
- An [OpenRouter](https://openrouter.ai/keys) API key with a small credit balance

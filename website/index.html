Features

Built for power users who care about cost and quality

ARIL runs a local gateway on your Mac, connects to OpenRouter, and helps you choose the right model for every task — without leaving the desktop.

Auto · Manual · Judge

Let ARIL route by category, lock a model, or compare three providers side-by-side and pick a winner.

Prompt intelligence

Grade, token estimate, latency probe, and rewrite suggestions while you type — before you spend.

Cost transparency

Per-message cost footers, session totals, budget guardrails, and OpenRouter credit status in the footer.

Learning loop

Prefer a Judge winner and Auto promotes that model next time for the same kind of prompt.

Local guardrails

Redact sensitive patterns and block prompt-injection attempts before they leave your Mac.

MCP tools

Built-in nmap and Semgrep scanners over MCP, plus slash commands for status, scans, and updates.

Skills

Local OS Access for shell tasks and Document Export for PDF/Word — pick with @ in the prompt or Preferences → Skills.

Project files

Attach Word, Excel, PDF, RTF, or Markdown to a Project. Sessions pull relevant excerpts into context automatically.

In the app

See it working

Intelligence before you send

Prompt grade, category, confidence, cost estimate, and an improved prompt alternative — all in one panel.

Clear, streaming replies

Markdown renders legibly in chat. Every reply shows the model, tokens, and exact OpenRouter cost.

Judge three models at once

Run the same prompt across matched models. ES scores help you Prefer a winner — Auto can promote it next time.

Spend analysis

Month, rolling 7-day, and today totals with a per-model breakdown from your local spend ledger.

300+ OpenRouter models

Browse and filter the live catalog — coding, vision, cost, performance — then lock a model in Manual mode.

Local skills

Document Export and OS Access run on your Mac. Type @ in the prompt to pick a skill, or let context enable them.

Managed MCP scanners

Local nmap and Semgrep servers launch when enabled — fresh bearer tokens, localhost-only, Check to verify tools.
